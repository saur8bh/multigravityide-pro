Powerful Architecture

Built for Serious Multi-Account Workflows

Designed to eliminate the friction of switching between client projects, personal accounts, and AI development environments.

Antigravity 2.0 Engine

Directly integrates with Google's separated Antigravity IDE standalone executable, custom process namespaces, and isolated .antigravity-ide extension trees.

antigravity-ide ready

Auth-Only Profiles

Most developers only need separate accounts. Auth-only profiles share your settings and extensions via intelligent symlinks, reducing disk footprint from 500MB to 2MB.

new work --auth-only

Profile Templates

Configure the perfect Python, Next.js, or AI tool environment once, save it as a template, and stamp out instant copies for new clients in seconds.

template save work py-dev

Live Process Dashboard

Instantly inspect running vs stopped profiles, profile types, last active timestamps, and live disk consumption at a glance.

multigravity status

Export & Import

Bundle any profile into a single portable .zip or .tar.gz archive. Migrate between laptop and desktop or share dev configs with teammates.

export work ./work.zip

Native Desktop Shortcuts

Every profile automatically registers as a native desktop application: Start Menu shortcuts on Windows, .app bundles in macOS Applications, and .desktop files in Linux.

1-click profile launch
Efficiency Benchmark

Full Profile vs. Auth-Only Profile

Choose between full sandboxing or intelligent symlinked auth isolation.

Full Profile

Completely independent sandbox. Best when you need unique extensions, different theme plugins, and separate settings.

~500 MB Disk per profile
  • Isolated Google & Antigravity Accounts
  • Independent Extension Directory
  • Independent Settings & Keybindings
  • Higher storage usage per instance
99% Less Disk Space

Auth-Only Profile

Shares your extensions and keybindings via smart symlinks. Only the account login tokens are separated.

~2 MB Disk per profile
  • Isolated Google & Antigravity Accounts
  • Shared Extensions (No re-installing plugins)
  • Shared Settings & Keybindings
  • Lightning fast profile creation
Quick Start

Up and Running in 3 Steps

No complex setup. Get isolated environments running in under 30 seconds.

1

Create a Profile

Name it after your company, client, or workflow. Add --auth-only to share extensions.

multigravity new client-a --auth-only
2

Launch Antigravity IDE

Opens Antigravity IDE with isolated session cookies, credentials, and settings.

multigravity client-a .
3

Enable Tab Completion

Get instant autocomplete for all commands and profile names directly in your terminal.

multigravity completion

Command Palette

Complete Command Reference

Full syntax cheat sheet for all Multigravity operations.

Command Category Description
multigravity new <name> Profile Create a new full profile with isolated user data and extensions
multigravity new <name> --auth-only Profile Create a lightweight profile sharing extensions & settings (~2MB)
multigravity new <name> --from <tpl> Template Create a new profile stamped out from a saved template
multigravity <name> [args...] Profile Launch Antigravity IDE with the isolated profile directory
multigravity list Profile List all configured profile names
multigravity status System Show running/stopped state, profile type, last used, and disk size
multigravity clone <src> <dest> Profile Duplicate an existing profile with all its configuration and data
multigravity rename <old> <new> Profile Rename a profile and automatically update its desktop launchers
multigravity delete <name> Danger Permanently delete a profile and its isolated directory
multigravity template save <prof> <tpl> Template Save an existing profile configuration as a reusable template
multigravity template list Template List all saved profile templates
multigravity template delete <name> Template Remove a saved template from disk
multigravity export <name> [path] Backup Export a profile to a portable .zip or .tar.gz archive
multigravity import <archive> [name] Backup Import a profile archive into your local Multigravity store
multigravity doctor System Verify Antigravity IDE detection, PATH registration, and profile health
multigravity stats System Display detailed storage breakdown and extension counts per profile
multigravity update System Self-update Multigravity scripts to the latest GitHub release
multigravity completion System Display shell autocomplete installation instructions for bash & zsh
multigravity uninstall [--force] Danger Completely remove Multigravity, all profile data, and shortcuts
Safe Removal

Complete Uninstallation

Permanently cleans up Multigravity, all created profiles, desktop launchers, and binary files.

Confirmation Required Before Deletion

An interactive confirmation prompt ([y/N]) is shown before anything is removed. To run unattended in scripts, append --force.

Option 1: Using the Installed CLI
multigravity uninstall
Option 2: Standalone PowerShell One-Liner (Windows)
irm https://raw.githubusercontent.com/saur8bh/multigravityide-pro/main/uninstall.ps1 | iex
Option 3: Standalone Bash One-Liner (macOS / Linux)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/saur8bh/multigravityide-pro/main/uninstall.sh)"
