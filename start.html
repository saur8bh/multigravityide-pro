Before we start

What are these tools?

If you're hearing words like "IDE", "terminal", and "profiles" for the first time, here is what they mean.

Antigravity

A smart notepad for code. You describe what you want to build in plain English, and the AI writes the code. You don't need prior programming knowledge.

Profile / Workspace

Like separate user accounts on your computer. Each one has its own isolated login, extensions, and projects — completely separated from the others.

Multigravity

The tool that lets you create and switch between those isolated spaces in one second, or even run multiple at the exact same time.

Step-by-step

Setup Guide

Follow these steps in order. Each one explains what to do, where to click, and what you should expect to see.

0
Make sure Antigravity is installed

You need the Antigravity IDE on your computer before using Multigravity. If you already have it, skip to Step 1. If not, download it from the official Google Antigravity website and install it.

How to check: Look in your Applications folder (macOS), Start Menu (Windows), or run which antigravity-ide in your terminal (Linux). If it's there, you're all set.
1
Open your terminal

A terminalA text-based way to talk to your computer. Instead of clicking buttons, you type short commands. Think of it as texting your computer. is where you run setup commands.

Press Command + Space on your keyboard. Type Terminal and press Enter. A window with text appears — that is your terminal.

Click the Start button on Windows, type PowerShell, and open Windows PowerShell.

Important: Use PowerShell, not Command Prompt. PowerShell handles script downloads properly.

Press Ctrl + Alt + T to launch the terminal on most Linux systems.

2
Install Multigravity

Click Copy on the command below, paste it into your terminal, and press Enter. Everything installs automatically. 

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/saur8bh/multigravityide-pro/main/install.sh)"
How to paste on macOS: Press Command + V, then press Enter. 
irm https://raw.githubusercontent.com/saur8bh/multigravityide-pro/main/install.ps1 | iex
How to paste in PowerShell: Right-click anywhere in the PowerShell window, and the text will paste. Then press Enter.

Wait 10–20 seconds while files download. You will see a success message when complete.

3
Verify the installation

Type this command and press Enter to run an automatic environment check:

multigravity doctor

You should see green checkmarks confirming that Antigravity IDE was detected and your profile storage is ready.

4
Create your first workspace

Pick a name for your workspace (like my-project, work, or client-a): 

multigravity new my-project --auth-only
Tip: Adding --auth-only shares your extensions and settings while isolating your account login, using only ~2MB of disk space!
5
Open your workspace

Launch Antigravity IDE with your isolated profile:

multigravity my-project

Antigravity opens in its own isolated window. You can also click the newly created shortcut on your desktop or Start Menu!

Setup Complete!

Here is what you just accomplished:

  • ✓ Installed Multigravity Pro
  • ✓ Verified Antigravity IDE detection with doctor
  • ✓ Created your first isolated profile
  • ✓ Launched Antigravity in separate user data space
Next steps

Helpful Commands to Know

Single-line commands you can use anytime in your terminal.

More workspaces

Run multigravity new second-project to create another sandbox.

List workspaces

Run multigravity list to see all your created profiles.

Check status

Run multigravity status to see running/stopped profiles and disk size.

Save as template

Run multigravity template save work py-dev to reuse an environment.

Quick login switch

Run multigravity new client --auth-only for a lightweight 2MB profile.

Complete uninstall

Run multigravity uninstall if you ever want to safely remove all data.

Reference

Glossary

Technical terms explained in plain language.

TerminalA text window where you type commands (Terminal on macOS, PowerShell on Windows).
IDE"Integrated Development Environment" — a code editor like Antigravity IDE.
ProfileAn isolated space with its own login, extensions, and settings.
Auth-onlyA lightweight profile that isolates login credentials while sharing plugins (~2MB).
TemplateA saved copy of a configured profile used to quickly stamp out new workspaces.
